# 릴스 업로드 패키지 (짧은 문구 버전)

캡션(추천)
회의실 온도, 말보다 먼저 투표 시작
더워요/괜찮아요/추워요 한 번씩 누르면
실시간 집계로 바로 조절 기준 확정

#눈치온도 #온도투표 #사무실 #회의실 #익명투표 #오피스 #온도관리 #인스타릴스 #팀워크

컷별 자막(요약)
1) 회의실 온도, 말보다 먼저 투표 시작
2) 방 만들고 링크 공유하면 바로 참여
3) 한 명의 불편함도 시작이 된다
4) 각자 한 번씩, 집계가 만들어진다
5) 의견이 모이면 기준이 선명해짐
6) 숫자가 조절 시점을 알려줌
7) 눈치 대신 데이터로 바로 결정

추천 업로드 톤
- 직관적, 짧은 문장 위주
- 핵심은 "익명, 실시간, 즉시 집계"
